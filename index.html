Ichorix (ранее GryazWorld)

Веб-платформа и инфраструктура для Minecraft-сервера

Личный проект: сайт, backend и игровой плагин, объединённые в одну экосистему. Развёрнуто в Docker на VPS. Проект остановлен в августе 2026.

  • Backend на FastAPI + SQLAlchemy + SQLite: 123 эндпоинта — авторизация, платежи, внутриигровой банк, штрафы, общины, статистика
  • Платежи через ЮKassa: очередь выдачи товаров, повторные попытки при сбое
  • Авторизация через Discord и Twitch OAuth, JWT-сессии
  • Взаимная аутентификация плагина и сайта по общему секрету
  • Frontend: React + Vite, мобильная адаптация, встроенная веб-карта (Pl3xMap)
  • Discord-бот: уведомления, интеграция с веб-частью
  • Деплой: Docker Compose, HTTPS через Let's Encrypt, отдельный Velocity-прокси

Игровая часть на Java 21 (Paper API 1.21.1):

  • Система персонажей и ролей — около 45 классов
  • Синхронизация инвентарей между серверами
  • Глобальный таб через сеть Velocity
  • Система наказаний с базой данных
  • Кастомные порталы и межсерверная телепортация
  • ATM с GUI и внутриигровой банк
  • Декомпиляция и доработка сторонних плагинов
