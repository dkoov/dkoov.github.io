GryazWorld — платформа

Веб-платформа и инфраструктура для Minecraft-сервера

Личный проект: сайт, плагин для игры и backend, объединённые в одну экосистему. Авторизация через Discord OAuth, серверная авторизация по JWT, развёрнуто в Docker на VPS.

  • Frontend: React + Vite, мобильная адаптация, встроенная веб-карта (Pl3xMap)
  • Backend: FastAPI + SQLAlchemy + SQLite, REST API, JWT-сессии
  • Minecraft-плагин на Java (Paper 1.21.1): межсерверная телепортация, ATM с GUI, система ролей
  • Discord-бот, OAuth2, уведомления, интеграция с веб-частью
  • Деплой: Docker Compose, HTTPS через Let's Encrypt, отдельный Velocity-прокси
  • В работе: интеграция платежей через ЮKassa, 2FA для аккаунтов
